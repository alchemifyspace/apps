# apps.alchemify.space

Product site for Alchemify's CodeCanyon apps: landing pages, live demo links, documentation and support. Plain HTML and CSS, published by GitHub Pages from `main`.

- `index.html`: all apps
- `glamio/`: Glamio landing page, `demo/`, `docs/` (copied from the Glamio repo's `documentation/`), `changelog/`
- `support/`: support policy and custom work
- Demo APKs are attached to this repo's Releases, not committed.

To update the Glamio docs: copy `glamio-salon-app/documentation/` over `glamio/docs/`.
