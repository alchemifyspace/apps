Try Glamio

Short on time? Watch the 2-minute video first. A demo salon, "Glamio Studio", with four stylists, twelve services and two weeks of bookings. Change anything you like: everything goes back to the start every night at 04:00 UTC.

Web admin (owner)

The salon owner's control panel. Works in any browser, also on a phone.

  1. Open the web admin.
  2. Click Log in as owner (demo). No email needed.
  3. Look at the dashboard and calendar, add a walk-in, edit a service or a stylist.
Open the web admin

Android app (client and stylist)

The phone app, connected to the same demo salon. Android 7.0 or newer, about 62 MB.

  1. Download the file on your Android phone and open it.
  2. If asked, allow your browser to install unknown apps. This is normal for apps from outside Google Play.
  3. Open Glamio, go to sign-in and under Demo build tap Customer or Staff.

About the demo

  • Everyone shares the same demo accounts, so you may see other visitors' bookings.
  • Push notifications are switched off in the demo app, because the accounts are shared. They work in your own copy; see the documentation.
  • There is no iPhone demo build. The same source code builds for iPhone.
  • Please don't enter real personal data.
